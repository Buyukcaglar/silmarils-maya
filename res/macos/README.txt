Le Fétiche Maya 64bit v1.0.0 (macOS)
====================================

A native 64-bit port of Le Fétiche Maya (Silmarils, 1989), made by statically
recompiling the Amiga version. One universal application for Apple silicon and
Intel Macs, macOS 11 Big Sur or later. Signed and notarized by Apple.

THE GAME IS NOT INCLUDED. You need the original Amiga game's files: the folder
that holds MAIN.CO and the other .CO files (in the WHDLoad package of the game
it is Maya/data).

Starting
--------
Drag "Le Fetiche Maya 64bit" to Applications and open it. The first time, it
asks for the game's folder and remembers it. You can also put the game's files,
or its "data" folder, next to the application, or start it from Terminal with
    open "/Applications/Le Fetiche Maya 64bit.app" --args --data <folder>

If the game's folder is in Documents, Desktop, Downloads or on an external
drive, macOS asks once whether the game may read it: allow it.

Controls
--------
Move the hero / the menu hand   Arrow keys or numeric keypad; game controller
Fire / select                   Control (either one), keypad 0, keypad Enter;
                                controller A or B
Leave the logo                  Any key
Start a game                    ?
Load the saved game             L (at the start prompt)
The game's icons                F1 to F10 (F10 saves). On a Mac keyboard, hold
                                fn with the F key, unless the keyboard settings
                                use F1, F2 etc. as standard function keys.
Full screen                     Control+Command+F (or the window's green button)

Letters and ? follow your keyboard layout. The Command key stays the Mac's:
Command+Q quits, Command+H hides.

Options
-------
The View menu: Enter Full Screen, Integer Scaling or Fit to Window, 4:3 Monitor
Aspect, CRT Scanlines. "About Le Fétiche Maya 64bit" is in the application menu.

Settings (maya64.cfg) and saved games (saves) are kept in
    ~/Library/Application Support/Le Fetiche Maya 64bit
The game's own folder is never changed.
